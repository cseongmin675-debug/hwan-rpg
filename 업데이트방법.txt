환 RPG 온라인 서버 업데이트 안내

1. 이 ZIP 파일을 압축 해제합니다.
2. 먼저 각 플레이어가 게임에서 캐릭터 백업 파일을 받아 둡니다.
3. 기존 GitHub 저장소 (cseongmin675-debug/hwan-rpg)에서 index.html만 새 파일로 교체합니다.
4. Commit changes (변경사항 저장)을 누릅니다.
5. Render의 기존 서버 hwan-rpg-1 배포가 성공했는지 확인합니다.
6. 기존 주소 https://hwan-rpg-1.onrender.com 을 그대로 사용합니다.

수정 내용
- 순간이동 후 카메라가 목적지로 이동하며 종이 1장 차감
- 테이머 늑대 소환 및 자동 공격 (2분 유지)
- 직업별/기술별 서로 다른 효과와 피해량
- 숨겨진 직업 30레벨의 더 어려운 2차 전직 시험
- 신규 몬스터 50종과 지역별 보스 5종

주의: 현재 온라인 서버는 플레이어 위치와 채팅을 공유하고 몬스터 전투 판정은 각 브라우저에서 계산합니다. 서버 공동 전투 기능은 포함되지 않습니다.
기존 저장 정보는 브라우저에 저장되며 별도 계정 서버와 자동 동기화되지 않습니다.
