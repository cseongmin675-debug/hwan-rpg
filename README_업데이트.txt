환 RPG 온라인 대확장판

업데이트한 파일:
- index.html: 기존 환 RPG 전체 게임 및 신규 직업 30종, 네크로맨서/테이머 소환, 장비 드롭, 파티·대결 UI, 히든 스킬 합성 극한 시련
- server.js: 온라인 파티 초대/탈퇴, PvP 1:1 대결 요청·타격, 파티 보너스 경험치 지원, 기존 PostgreSQL 클라우드 저장 기능 유지
- package.json: ws와 pg 사용

사용법:
1. ZIP 파일을 압축 해제합니다.
2. GitHub 저장소 cseongmin675-debug/hwan-rpg의 main에서 위 세 파일을 모두 교체합니다.
3. Commit changes를 누르고 Render 배포 완료를 확인합니다.
4. https://hwan-rpg-1.onrender.com 에서 친구와 동시에 접속하면 소셜 기능이 활성화됩니다.
5. 브라우저 저장 데이터는 삭제하지 마세요. 기존 계정은 기기별 저장 또는 기존 연결된 클라우드 저장을 사용합니다.

조작: 네크로맨서 스킬 1~3 해골 소환(최대 10, HP100 ATK150); 테이머 늑대 0키 해제; 히든 직업 ... 스킬 합성 극한 퀘스트는 Lv5 이상부터 시작 가능.
참고: 온라인 대결은 친선전이며 별도 랭킹/재화 보상은 없습니다. 온라인 멀티플레이 검증은 실제 배포 후 필요합니다.
