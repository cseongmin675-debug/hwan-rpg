환 RPG 온라인 멀티플레이 — 실행 안내

포함 파일: index.html (게임), server.js (온라인 서버), package.json

[내 컴퓨터에서 실행하기]
1. Node.js 18 이상 설치: https://nodejs.org
2. 압축 해제한 폴더에서 터미널/명령 프롬프트 실행
3. npm install
4. npm start
5. 브라우저에서 http://localhost:3000 열기

[친구와 인터넷으로 접속하기]
위 서버는 내 PC에서만 자동으로 공개되는 것은 아닙니다.
Render.com 같은 Node.js 웹 서버 호스팅에 이 3개 파일을 업로드하거나 GitHub 저장소로 배포하세요.
- 빌드 명령: npm install
- 시작 명령: npm start
- 서버 환경 변수: PORT (호스팅이 자동 제공하면 별도 설정 불필요)
- 웹 서비스 URL(예: https://내서버주소.onrender.com)을 친구에게 공유하세요.
- 서버가 실행 중이어야 접속 가능하며, 무료 호스팅은 휴면 시 접속이 지연될 수 있습니다.
- 이 파일 자체를 더블클릭해서 열면 싱글플레이는 되지만 온라인 연결은 안 됩니다.

[이번 버전의 온라인 기능]
같은 서버에 접속한 이용자의 캐릭터 위치와 이름/레벨 표시, 접속/퇴장 알림, 채팅 공유.
기존 몬스터 전투, 퀘스트, 골드, 아이템, 전직은 아직 각 플레이어 브라우저에서 독립적으로 계산됩니다.
즉, 공동 사냥·파티·거래·PVP·서버 계정/영구 캐릭터 저장은 아직 구현되지 않았습니다.
기존 저장 기록은 브라우저/사이트별로 분리됩니다. 기존 파일의 로컬 저장 데이터는
사이트 주소가 달라지면 자동으로 옮겨지지 않을 수 있습니다.

[주의]
외부 인터넷 공개 서버의 테스트용 초기 구현입니다.
실제 대규모 운영 시 회원 인증, 서버 권한 검증, 어뷰징 방지와 DB 저장이 추가로 필요합니다.
